## Calidad visual de interfaz

Antes de la primera decisión visual —plan, análisis y review incluidos— abre y aplica `POLICY_PATH` si la tarea propone, crea, modifica o revisa UI visible. También si una feature agrega UI.

No lo abras para SQL, API sin superficie, git o infra.

El archivo elige una skill principal por superficie. En la misma delegación cabe un solo apoyo que no sea dirección: `accessibility` o `web-design-guidelines`, no los dos. Las referencias internas no cuentan como skills. Las preferencias visuales no impiden corregir el defecto dentro del alcance. Contratos, stack, accesibilidad y dependencias siguen vigentes.

"Visual style" de PHP/TS es formato, no acabado.
